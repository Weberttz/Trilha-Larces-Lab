# Projeto final do curso Python Essentials da Cisco

Este diretório contém o projeto final do curso de Fundamentos do Python 1 da Cisco Networking Academy, desenvolvido como parte da prática de programação em Python.

## Objetivo

O foco desta pasta é demonstrar a aplicação dos conceitos aprendidos durante o curso, especialmente:

- lógica de programação;
- estruturas de controle;
- funções;
- manipulação de listas e matrizes;
- entrada e saída de dados;
- desenvolvimento de um jogo simples em Python.

## Arquivo principal

- `velha.py`  
  Implementa o clássico jogo da velha, com interação do usuário, lógica para validar jogadas, verificação de vitória e inteligência simples do computador.

## Observação

A estrutura e a lógica do código foram desenvolvidas com base nos conceitos do curso, mostrando a evolução do aprendizado de programação em Python.
